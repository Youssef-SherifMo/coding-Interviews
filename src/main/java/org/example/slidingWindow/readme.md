## Pattern (Problem)

Many problems dealing with an array (or a LinkedList), we are asked to find or calculate something among all the contiguous subarrays (or sublists) of a given size.

example:
>  Given an array, find the average of all contiguous subarrays of size ‘K’ in it.
> 
input: <br>
`Array: [1, 3, 2, 6, -1, 4, 1, 8, 2], K=5` <br>
output: <br>
`Output: [2.2, 2.8, 2.4, 3.6, 2.8]` <br>
